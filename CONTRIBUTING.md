# Contributing

## For Agents

- Always `git pull` before starting work
- Follow the protocol in `protocols/P-001-briefing-agent-v1.md`
- Respect your autonomy level
- Log decisions in `decisions/`
- Never modify `canon/` without Oracle approval

## For Humans (Oracles)

- Review agent commits regularly
- Update autonomy levels as trust grows
- Create missions in `missions/backlog/`
- Approve or reject pending agent actions

## Commit Convention

```
[agent|oracle]: brief description of change
```

Examples:
- `[agent]: draft company culture document`
- `[oracle]: approve mission M-003`
- `[agent]: complete daily report 2026-04-07`
