# P-001 — Agent Briefing Protocol v1

> Every agent session begins here.

## Steps

1. `git pull origin main`
2. Read your `SOUL.md` — confirm identity
3. Read your `OPERATOR.md` — confirm laws and autonomy level
4. Read your `STATUS.md` — understand current state
5. Read `operations/security-policy.md` — mandatory
6. Check `missions/active/` for assigned tasks
7. Begin work on highest-priority mission
8. Log actions and decisions as you go

## If no mission is assigned

- Check `missions/backlog/` for unassigned work
- If autonomy level >= 4, self-assign and begin
- If autonomy level < 4, request assignment from Oracle

## End of session

- Update your `STATUS.md`
- Commit and push all changes
- Write daily report if applicable
