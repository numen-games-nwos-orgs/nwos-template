# Standards

## File Naming

- Canon: `C-NNN-title.md`
- Protocols: `P-NNN-title-vN.md`
- Decisions: `ADR-NNN-title.md`
- Missions: `M-NNN-title.md`
- Reports: `YYYY-MM-DD-type.md`

## Document Structure

Every document must include:
- A title as H1
- A status or metadata block
- Clear sections with H2 headers

## Language

All documents in English unless specified otherwise in canon.

## Git Workflow

- `main` branch is the source of truth
- Agents work on `main` directly (within autonomy level)
- Major changes require a PR reviewed by Oracle
