# Governance

## Decision Authority

| Decision Type | Authority | Process |
| --- | --- | --- |
| Canon changes | Oracle consensus | ADR required |
| New agent deployment | Oracle | Approval required |
| Mission creation | Oracle or Agent (level >= 4) | Log in missions/ |
| Protocol updates | Oracle | ADR recommended |
| Autonomy level changes | Oracle only | Documented in config |

## Autonomy Levels

| Level | Description |
| --- | --- |
| 1-3 | Agent requests permission for every action |
| 4-6 | Agent can draft and edit, cannot publish |
| 7-9 | Agent can publish, cannot delete or restructure |
| 10 | Full autonomy |
